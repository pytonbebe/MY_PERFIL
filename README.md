## Deploy en Vercel

1. Sube este repo a GitHub  
2. En [vercel.com](https://vercel.com) → **New Project** → importa el repo  
3. Framework: **Vite** (detectado automático)  
4. Build: `npm run build` · Output: `dist`  
5. Deploy  

O con CLI:

```bash
npm i -g vercel
vercel
```
